{\sffamily\bfseries\huge\color{slate} Krushna's part, as a flow}\par
{\large Prarup \textperiodcentered{} Building the IEEE PDF, and checking it}\par
\medskip
\textbf{The story:} models first, then judge the manuscript, then write LaTeX, then compile, then mark and measure figures, then check the PDF, then fit figures, then fix fonts.

\begin{center}\small\ttfamily
models \(\rightarrow\) analyze \(\rightarrow\) renderer \(\rightarrow\) compile \(\rightarrow\) figures \(\rightarrow\) measure \(\rightarrow\) checks \(\rightarrow\) fit \(\rightarrow\) fix
\end{center}
\textbf{Memory hook ``M-A-R-C-F-M-C-F-F'':} \emph{My Arts Report Can't Fail; My Checks Fit Fine.}

\section{models.py: the data boxes (built first)}
Plain classes that carry data between files. Each \cc{\_\_init\_\_} only stores values on \cc{self}.
Order to remember, ``I R A G M G F F'': \emph{I Read A Good Magazine; Great For Fun.}

\toprule
\textrm{\textbf{Class}} & \textbf{Holds} & \textbf{Special} & \textbf{Used in}\\
\midrule
Issue & code, message, severity, can\_fix & & checks (every PDF problem), project (GEOM-03)\\
Rules & page\_limit 6, columns 2, body font 10, min figure text 7 & \cc{@classmethod load} reads ieee.yaml & checks, fit, project, window\\

\textbf{Python used:} classes, \cc{\_\_init\_\_}/\cc{self}, default arguments, \cc{@classmethod} with \cc{cls}, \cc{@property}, \cc{\_\_eq\_\_} returning \cc{NotImplemented}, \cc{yaml.safe\_load}, \cc{vars()}, \cc{**data}, \cc{raise ValueError}.
\remember{Graphic is the figure in LaTeX, Measured is where it landed on the PDF, Geometry is the page it is compared with. Issue is a PDF problem; Rules are the limits.}

\section{analyze.py: what is missing? (before building)}
Checks the \textbf{manuscript}, not the PDF, and returns \cc{Finding}s for the Missing tab.
\begin{itemize}
\item \cc{PLACEABLE} (png jpg pdf), \cc{CONVERTIBLE} (gif bmp tif webp)
\item \cc{@dataclass Finding}: code, severity, message, block\_id, group
\item \cc{\_cited\_keys} (\cc{@key}, \cc{\textbackslash cite\{\}}), \cc{\_numeric\_citations} ([3], [2-4]), \cc{\_roman} (IV \(\rightarrow\) 4), \cc{\_mentions} (labels and numbers)
\item \cc{analyze(m, project)}: \textbf{META} \(\rightarrow\) \textbf{FIG} \(\rightarrow\) \textbf{TAB} \(\rightarrow\) \textbf{REF} \(\rightarrow\) \textbf{STR}
\end{itemize}
\textbf{Python used:} \cc{@dataclass}, \cc{lambda *a, **k}, sets and set difference, regex \cc{findall}/\cc{split}, \cc{enumerate(start=1)}, \cc{map(int, ...)}, \cc{range(a, z+1)}, \cc{next(..., "")}.
\remember{Models are not used here; it has its own Finding, which images.py reuses.}

% ---------------------------------------------------------------
\section{renderer.py: Manuscript to IEEE LaTeX}
Writes \cc{paper.tex} by rebuilding the paper in our template \cc{ieee.tex.j2} with \textbf{Jinja2}.
\begin{itemize}
\item \cc{\_env}: Jinja with \cc{\textbackslash VAR\{\}} and \cc{\textbackslash BLOCK\{\}} markers (no clash with LaTeX braces)
\item \cc{\_plain\_heading} (drop ``2.1''), \cc{\_flatten\_tables}, \cc{\_bounded} (deepcopy, drop image sizes), \cc{\_cells}
\item \cc{\_table\_latex}: 4.5 pt per character; over 1.6 columns \(\rightarrow\) \cc{table*}; tabularx / adjustbox
\item \cc{\_figure\_latex}: fitted width, or an ``image missing'' box; \cc{\_references\_latex}: \cc{\textbackslash bibliography} or thebibliography
\item \cc{body\_latex}: every block, batched pandoc calls; \cc{\_unwrap\_environments}: align inside \cc{\textbackslash[ \textbackslash]}; \cc{\_lines}: break affiliations
\item \cc{render(m, project)}: front matter in one call, body, template
\end{itemize}
\textbf{Python used:} Jinja2, \cc{copy.deepcopy}, nested functions, regex \cc{sub}, \cc{dict(zip(...))}, \cc{iter}/\cc{next}, \cc{range(0, n, 2)}.
\remember{We rebuild instead of compiling the author's LaTeX, which is why all 6 real papers compile.}

\section{compile.py: run Tectonic}
\cc{TectonicNotFound} and \cc{compile\_pdf(tex, out\_dir)}: find tectonic, \textbf{delete the old PDF first}, run, return \cc{(pdf, log)}. The caller checks \cc{pdf.exists()}.
\textbf{Python used:} custom exception, \cc{Path.unlink(missing\_ok=True)}, \cc{run\_tool} from process.py.
\remember{Delete the old PDF so a failed compile is never checked against an old file.}

% ---------------------------------------------------------------
\section{figures.py: find and mark figures (creates Graphic)}
Works on the \textbf{.tex text}.
\begin{itemize}
\item Constants: \cc{\_GRAPHIC}, \cc{\_ENV}, \cc{\_NESTED\_BOXES}, \cc{\_SIZE\_KEYS}, \cc{MEASURE\_HOOK} (defines \cc{\textbackslash prarupfig}, writes geometry into the PDF)
\item \cc{\_comment\_spans}, \cc{\_in\_any}, \cc{\_figure\_envs} (begin/end matched with a \textbf{stack})
\item \cc{find\_graphics(tex)} \(\rightarrow\) list of Graphic, with a reason if it cannot be resized (two images, nested box, rotated, not in a figure)
\item \cc{\_split\_options} (commas outside braces), \cc{set\_width}
\item \cc{resize(tex, changes)}: new widths, figure \(\leftrightarrow\) figure*; edits applied \textbf{from the end backwards}
\item \cc{instrument(tex)}: wraps each graphic in an invisible link \cc{prarup:fig:N}
\end{itemize}
\textbf{Python used:} named regex groups, list as a stack, \cc{max(..., key=lambda)}, \cc{sorted(reverse=True)}, \cc{*tuple} unpacking.

\section{measure.py: where did it land, how big is its text? (creates Measured)}
\begin{itemize}
\item Constants: \cc{BITMAP}, \cc{EXTENSIONS}, \cc{TALL}/\cc{TAIL} letters, \cc{TOLERANCE = 2.0}
\item \cc{graphic\_boxes(doc)}: the \cc{prarup:fig:N} links \(\rightarrow\) \{N: (page, rect)\}
\item \cc{small\_text}: \textbf{median of the smaller half} (tick labels matter, not titles)
\item \cc{vector\_text}: font sizes of PDF text inside the box (vector figures)
\item \cc{\_OCR\_CACHE}, \cc{ocr\_text\_per\_width} (cache by path and time), \cc{\_ocr\_text\_per\_width}: Tesseract; height \(\div\) 0.96 or 0.76; confidence \(\geq\) 80
\item \cc{find\_file}; \cc{measure(pdf, graphics, dir)} \(\rightarrow\) (Geometry, [Measured]) with overflow via \cc{Geometry.bounds}
\end{itemize}
\textbf{Python used:} \cc{csv.DictReader} over \cc{io.StringIO}, \cc{statistics.median}, module-level dict cache, \cc{pymupdf.Rect}/\cc{Point}.
\remember{Vector figure: read the font size from the PDF. Bitmap: Tesseract word height. Divide by width to get size per width.}

\section{checks.py: does the PDF pass IEEE? (creates Geometry and Issue)}
Only reads the PDF; \cc{test\_layering} enforces it never runs programs.
\begin{itemize}
\item \cc{UnreadablePdf}, \cc{\_open} (\cc{raise ... from exc}), \cc{plain\_font\_name} (\cc{partition}), \cc{describe\_pages}
\item \cc{read\_geometry(doc)} \(\rightarrow\) Geometry, from \cc{PrarupGeometry} in the PDF info
\item class \cc{PdfChecks(document, rules)}: \cc{run} (errors first), \cc{fonts} (FONT-01 n/a, can fix; FONT-02 Type3), \cc{page\_count} (GEOM-01), \cc{security} (DOC-01, can fix), \cc{bookmarks} (DOC-02), \cc{figure\_overflow} (GEOM-02, \(>\) 2 pt)
\item \cc{check\_fonts}, \cc{check\_page\_count}, \cc{check\_security}, \cc{check\_bookmarks}, \cc{check\_figure\_overflow}, \cc{run\_all\_checks}
\end{itemize}
\textbf{Python used:} a class sharing document and rules, bound methods in a tuple, \cc{with}, \cc{setdefault(...).append}, lookahead \cc{(?=pt)}, \cc{sorted(key=lambda)}.
\remember{Fonts (01 missing, 02 Type3), Geom (01 pages, 02 overflow, 03 small text), Doc (01 encrypted, 02 bookmarks).}

% ---------------------------------------------------------------
\section{fit.py: make figure text readable (creates FigureChange and FitReport)}
\begin{itemize}
\item Constants: \cc{SEARCH\_STEPS = 5}, \cc{SLACK = 2.0} pt, \cc{LIMIT\_FLOOR = 0.4}; exception \cc{FitFailed}
\item \cc{\_compile} (temporary .tex, \textbf{finally} deletes it), \cc{\_pages}, \cc{\_last\_page\_fill}, \cc{\_width\_expr} (rounded down)
\item \cc{plan}: target width \(= 7/k + 2\); wider than a column \(\rightarrow\) figure*; wider than the page \(\rightarrow\) re-export; policy readable or limit
\item \cc{fit\_paper}: find\_graphics \(\rightarrow\) instrument \(\rightarrow\) compile \(\rightarrow\) measure \(\rightarrow\) plan \(\rightarrow\) layout(t) \(\rightarrow\) \textbf{binary search} if over the limit \(\rightarrow\) resize \(\rightarrow\) measure again \(\rightarrow\) FitReport
\item \cc{\_size}, \cc{describe} (lines for the Figure fit tab)
\end{itemize}
\textbf{Python used:} \cc{try/finally}, \cc{math.floor}, nested functions (closures), binary search, tuple swap, lambdas.
\remember{Text grows with width: width = 7 / k. Too wide, two columns. Too many pages, binary search.}

\section{fix.py: Fix PDF}

\subsection{30-second viva story}
\emph{My part builds and checks the PDF. models.py holds the data classes. analyze finds what is missing before
building. renderer rebuilds the paper in our IEEE template and compile runs Tectonic. figures marks each graphic
with an invisible link, measure finds where it landed and how big its text is, and checks inspects fonts, pages
and overflow like PDF eXpress. fit resizes figures until their text is 7 pt, using binary search when the page
limit is tight, and fix embeds missing fonts with Ghostscript.}
