@purpose
**Fix PDF**: repairs the problems that can be repaired automatically (missing fonts, encryption) by passing the PDF through **Ghostscript**, which rewrites it with every font embedded. `KEEP_IMAGES` tells Ghostscript not to shrink or recompress images, because a repair must not lower figure quality.

@imports
`sys` (to find a Ghostscript shipped next to Python on Windows), `Path`, and `find_tool` / `run_tool`.

== GhostscriptNotFound
Raised when no Ghostscript program can be found.

== RepairFailed
Raised when Ghostscript ran but produced no PDF, carrying its error text.

== find_ghostscript
Ghostscript has different names: `gs` on Mac and Linux, `gswin64c` or `gswin32c` on Windows. This tries each, then a copy inside the Python environment on Windows. Returns the path or None.
? Why three names?
! The program is called `gs` on Mac and Linux but `gswin64c` (64-bit) or `gswin32c` (32-bit) on Windows.

== embed_fonts
Runs Ghostscript to rewrite the PDF with all fonts embedded.
- `-dNOPAUSE -dBATCH -dSAFER -dQUIET`: run without stopping, exit at the end, do not allow file access from the PDF, print little.
- `-sDEVICE=pdfwrite`: write a PDF. `-dPDFSETTINGS=/prepress`: print-quality settings.
- `-dEmbedAllFonts=true -dSubsetFonts=true -dMaxSubsetPct=100`: embed every font (only the characters used).
- `*KEEP_IMAGES` unpacks the image settings into the command.
- It checks both the exit code and that the output file exists.
* Single Responsibility: the only place that runs Ghostscript.
? Why put KEEP_IMAGES after /prepress?
! Later options win. /prepress would otherwise downsample images; our settings after it switch that off.
? What does -dSAFER do?
! Stops the PDF from running file operations inside Ghostscript; a safety option for files from others.
? Why not fix fonts inside our own Python code?
! Embedding a font means rewriting the PDF's font programs; Ghostscript does this reliably, and it is free.
