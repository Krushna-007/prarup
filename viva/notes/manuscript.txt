@purpose
The **data model** of a paper inside Prarup. A `Manuscript` is the whole paper; a `Block` is one piece of its body (a heading, a paragraph, a figure...). Every other part of the program reads and edits these two classes. They are saved to `<paper>-prarup/manuscript.json` after every edit, and loaded again when the paper is reopened.

Both are **dataclasses**: you list the fields with their types and defaults, and Python writes `__init__`, `__repr__` and `__eq__` for you.

@imports
`json` to save and load, `asdict` (turns a dataclass into a dict, including nested ones), `dataclass` and `field`, and `Author` from models.

== Block
One piece of the paper. Fields, in groups:
- `id` ("b1", "b2"...), `kind` (heading, para, quote, list, code, raw, equation, figure, table, references), `text` (Markdown), `level` (1 for a section heading, 2 for a subsection), `node` (the original pandoc nodes, kept so tables and images can still be rewritten), `edited` (the user changed it), `detected` (why Prarup decided what it is, shown in the editor).
- Figures and tables: `images` (paths), `caption`, `label`, `number` (as written in the paper), `widths`, and `fit_width` / `double` chosen by Fit figures.
- References: `entries` (one Markdown string each) and `keys` (citation keys, when known).
`field(default_factory=list)` gives each block its **own** new empty list.
* Data class (a plain data carrier): fields only, no logic, so every part of the program can share it without depending on each other.
? Why field(default_factory=list) instead of `images: list = []`?
! A plain `[]` default would be one list shared by every Block, so adding an image to one block would add it to all. `default_factory` calls `list()` for each new object. (Dataclasses actually refuse `= []` for this reason.)
? Why does a Block keep the pandoc node as well as the text?
! Some things cannot be rebuilt from Markdown text alone: table cells and images inside paragraphs are written back from the node.
? What does @dataclass write for you?
! `__init__` (taking the fields as arguments), `__repr__` (a readable print-out) and `__eq__` (compare field by field).

== Manuscript
The whole paper: `source` (the original file path), `title`, `authors` (a list of `Author`), `abstract`, `keywords`, `blocks`, `bibliography` (name of a copied .bib file, if any), `api` (pandoc's version, reused when Prarup calls pandoc again), `notes` (things Prarup noticed while reading, shown in the Notes tab), `preamble` (the author's safe LaTeX lines), and `source_mtime` (when the source file was last changed, used to decide whether a saved copy is still valid).
? What is source_mtime used for?
! If the user edits the original .docx after opening it, its modification time becomes newer than the saved one, so Prarup reads the paper again instead of using the old saved copy.

== Manuscript.figures
Returns only the figure blocks, in order. A list comprehension filters `self.blocks`.
? How is "Figure 3" found in the code?
! `m.figures()[2]`: the third figure block, because lists start at 0.

== Manuscript.tables
Same as `figures`, for tables.
? Why are these methods and not stored lists?
! They are computed from `blocks` each time, so they can never be out of date after a block is moved or deleted.

== Manuscript.find
Returns the block with the given id, or `None`. `next(generator, None)` returns the first match, or the default `None` when there is none.
* Encapsulation: callers ask the manuscript for a block instead of searching its list themselves.
? What does next((b for b in ... if ...), None) do?
! It walks the blocks lazily, stops at the first one whose id matches, and gives `None` if none do, instead of raising StopIteration.

== Manuscript.save
Writes the manuscript to a JSON file. `vars(self)` gives the object's fields as a dict; authors and blocks are converted too (`vars(author)`, `asdict(block)`), because `json` only understands dicts, lists, strings, numbers, booleans and None. `.copy()` makes sure the object itself is not changed.
? Why .copy() before replacing "authors"?
! `vars(self)` is the object's real attribute dict; changing it would replace the object's authors with plain dicts. The copy is changed instead.
? Why can't json.dumps save an Author directly?
! JSON knows only basic types. Objects must first be turned into dicts.

== Manuscript.load
A **classmethod**: called on the class (`Manuscript.load(path)`), it reads the JSON, turns the author dicts back into `Author` objects and block dicts back into `Block` objects (`Block(**b)` passes each key as a keyword argument), then builds a Manuscript with `cls(**data)`.
* Factory method / alternative constructor: a classmethod that builds the object from a file.
? What is a classmethod and why use one here?
! It receives the class (`cls`) instead of an object. It is the usual way to write an alternative constructor: "make a Manuscript from a file".
? What does Block(**b) do?
! `**b` unpacks the dict: `{"id": "b1", "kind": "para"}` becomes `Block(id="b1", kind="para")`.
