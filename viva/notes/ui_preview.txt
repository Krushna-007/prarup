@purpose
Shows **one page of the PDF** on the right, with Previous and Next buttons and "Page 2 / 6". The page is drawn by PyMuPDF into an image, which is placed on a Tk `Canvas`. It is redrawn whenever the canvas changes size, so the page always fits.

@imports
`tkinter` (Canvas, PhotoImage), `ttk` (buttons, label), `pymupdf` (draw the PDF page), and the `LINE` colour.

== PdfPreview
Holds the current PDF path and page number, and the widgets.

== PdfPreview.__init__
Builds the Previous / page label / Next row and the canvas. The buttons call `draw(-1)` and `draw(1)`. Binding `<Configure>` (sent when the widget is resized) redraws the page at the new size.
? What is the <Configure> event?
! Tk sends it when a widget's size or position changes; here it redraws the page to fit the new size.

== PdfPreview.load
Shows a new PDF (or none) from its first page.
? What happens when load() is called with no path?
! `pdf` becomes None and the canvas is cleared to "PDF preview"; used while building so an old PDF is not shown.

== PdfPreview.draw
Clears the canvas; with a PDF, moves `step` pages (clamped between the first and last page), works out the scale that fits the page into the canvas, renders the page to pixels with that zoom (`get_pixmap(matrix=Matrix(scale, scale))`), turns them into a Tk image (PPM format, which Tk reads directly) and draws it centred at the top. The image is kept in `self.picture` so Tk does not lose it.
> canvas 600x800, page 612x792 pt  ->  scale = min(588/612, 788/792) = 0.96
? How is the page scaled to fit?
! The scale is the smaller of width ratio and height ratio, so the whole page fits both ways.
? Why convert to PPM?
! Tk's PhotoImage reads PPM data directly, without needing Pillow.
? Why `max(0, min(self.page + step, total_pages - 1))`?
! It keeps the page number between 0 and the last page, so Next on the last page stays there.
