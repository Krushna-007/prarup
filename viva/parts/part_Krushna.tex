\begin{cheat}{Numbers and facts to remember}
\begin{itemize}
\item IEEE column \textbf{252 pt} (3.5 in); 72 pt = 1 inch; page limit \textbf{6}; minimum figure text \textbf{7 pt}.
\item Table width estimate: 4.5 pt per character; over \textbf{1.6} columns \textrightarrow{} \cc{table*}.
\item Measuring: \cc{\textbackslash prarupfig\{N\}} wraps each graphic in an invisible link \cc{prarup:fig:N}; its rectangle is where the graphic is.
\item Geometry is written into the PDF by the template (\cc{PrarupGeometry}), read back by \cc{read\_geometry}.
\item OCR: word height \(\div\) 0.96 (tall + tail letters) or 0.76; confidence \(\geq 80\); smaller-half median.
\item Fitter: width for 7 pt = 7 / k + 2 pt slack; wider than a column \textrightarrow{} \cc{figure*}; 5 binary-search steps; limit layout down to 40\%.
\item Overflow tolerance 2 pt. GEOM-03: figure text below 7 pt.
\item FONT-01 not embedded (fixable), FONT-02 Type3 (re-export), GEOM-01 pages, GEOM-02 overflow, DOC-01 encrypted, DOC-02 bookmarks.
\end{itemize}
\end{cheat}

\begin{cheat}{The five questions you will surely get}
\textbf{1. Why rebuild the paper instead of compiling the author's LaTeX?} Real papers used pdfLaTeX-only packages and illegal \cc{longtable}s; our own template with only safe author packages made all six real papers compile.\par
\textbf{2. How do you find a figure's text size?} Vector figures: font sizes in the PDF inside the figure's box. Bitmaps: Tesseract word heights, converted with the printed width.\par
\textbf{3. How does Fit figures work?} Text grows with width, so the width for 7 pt is 7 / k. If that breaks the page limit, binary search finds the largest scale that fits, or the user picks between readable and within the limit.\par
\textbf{4. Why is a non-embedded font a problem, and how is it fixed?} IEEE needs all fonts embedded; matplotlib often leaves Helvetica out. Ghostscript rewrites the PDF with every font embedded.\par
\textbf{5. Why delete the old PDF before compiling?} A failed compile writes nothing; the old PDF would be checked and a broken paper reported as fine.
\end{cheat}
