\begin{cheat}{Numbers and facts to remember}
\begin{itemize}
\item One worker thread (\cc{ThreadPoolExecutor(max\_workers=1)}); the window polls every \textbf{80 ms} with \cc{root.after}.
\item Auto-rebuild \textbf{1.5 s} after the last edit; an edit during a build sets \cc{rebuild\_waiting}.
\item Every edit saves \cc{<paper>-prarup/manuscript.json} at once; reopening loads it unless the paper file is newer.
\item One build compiles once: an instrumented copy, measured, then markers stripped into \cc{paper.pdf}.
\item Editors never redraw the window while saving; \cc{save()} returns a message (this fixed a crash).
\item The outline row id is the block id ("b12") or title / authors / abstract / keywords.
\item Tests share one \cc{tk.Tk()}: macOS crashes if many roots are created and destroyed.
\item Export zip: paper.pdf, paper.tex, used images, refs.bib, prarup-report.md, README.txt.
\end{itemize}
\end{cheat}

\begin{cheat}{The five questions you will surely get}
\textbf{1. How does the window stay responsive during a build?} The build runs on a background thread. Tkinter is not thread-safe, so the thread only computes; the main thread checks every 80 ms with \cc{root.after} and draws the result.\par
\textbf{2. Why is there a Project class between the window and the modules?} The window is about buttons; Project is about papers. One place decides the order of steps, so the window code stays short, and tests can drive Project without a window.\par
\textbf{3. What happens when I click a problem in the Missing tab?} \cc{ProblemList.\_clicked} \textrightarrow{} \cc{MainWindow.jump} \textrightarrow{} the outline selects the block \textrightarrow{} the current editor is saved \textrightarrow{} the right editor is created by \cc{editor\_for}.\par
\textbf{4. How do edits survive closing the app?} Every Project edit method saves \cc{manuscript.json} immediately; \cc{Project.open} loads it next time.\par
\textbf{5. Why Tkinter?} It comes with Python, needs no extra install, and is simple enough to explain line by line; the heavy work is in the other modules.
\end{cheat}
