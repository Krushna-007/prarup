\chapter{Rapid fire: questions about the whole project}

\color{ink}\begin{enumerate}[leftmargin=2em, itemsep=0.5em]
\item \textbf{What problem does Prarup solve?} Authors lose days formatting papers for IEEE and find out about missing fonts, wide figures or missing captions only when PDF eXpress rejects the paper on deadline day. Prarup shows and fixes these before submission.
\item \textbf{What is new compared with just converting a file?} Three things: it shows what is missing and lets you fix it in place; it measures figures on the real PDF and resizes them until their text is readable; and it reports evidence of AI-generated images.
\item \textbf{"ChatGPT can do this too." Can it?} It cannot open your .docx, compile LaTeX, read which fonts are embedded in your PDF, measure figure text in points, or verify a signed C2PA record. Every check here is measured, and works offline.
\item \textbf{Why a desktop app?} It is a course requirement, and papers are private: nothing leaves the computer.
\item \textbf{Why Tkinter and not a web framework?} It ships with Python, runs on Windows, macOS and Linux, and is small enough to explain line by line.
\item \textbf{Why pandoc?} Writing our own Word and LaTeX parser would take months; pandoc reads both into one tree, so one piece of code handles both inputs.
\item \textbf{Why Tectonic instead of pdflatex?} It downloads the packages it needs automatically, so a user does not have to install a 4 GB TeX distribution.
\item \textbf{What libraries do you use, and for what?} PyMuPDF (read and draw PDFs), Pillow (images), Jinja2 (LaTeX template), PyYAML (rules), c2pa-python (signed image provenance); optional torch and transformers (classifier).
\item \textbf{How is the code organised?} Reading (Prateek), building and checking (Krushna), the window and the controller (Om). The window only talks to \cc{Project}; \cc{Project} calls the modules.
\item \textbf{How did you test it?} About 150 automated tests with pytest, on three real CC-BY papers from Zenodo, damaged copies of them (missing captions, abstract, a low-resolution image, a real AI image, a duplicate, a citation past the references), real AI images, and a test that drives the window through fixing a damaged paper.
\item \textbf{What did testing on real papers change?} At first only 2 of 5 real papers compiled. Real papers broke on \cc{longtable}, pdfLaTeX-only packages, nested maths and odd captions; after the redesign all 6 compile.
\item \textbf{What happens if pandoc or Tectonic is not installed?} A clear message (\cc{PandocNotFound}, \cc{TectonicNotFound}); tests that need them are skipped, not failed.
\item \textbf{Is the AI detection reliable?} A signed C2PA record is proof of where an image came from. Generator traces are strong hints. The classifier is only a likelihood, so we run it only on photos, after measuring 4 false alarms on 26 real charts. We say "evidence", never "this is AI".
\item \textbf{Why 7 pt for figure text?} Below about 7 pt, printed figure text becomes hard to read in a two-column paper; it is our chosen threshold, kept in the rules file.
\item \textbf{What are the limits?} Only the IEEE conference template; author detection covers the layouts we have seen; OCR text size is within about half a point on clean plots; a stripped AI image is only caught by the classifier.
\item \textbf{What would you add next?} More templates (ACM, Springer), PDF/A output, margin checks, clicking the PDF to jump to the block (SyncTeX).
\item \textbf{Where are a paper's edits stored?} In \cc{<paper>-prarup/manuscript.json}, next to the paper, saved after every edit.
\item \textbf{What is in the exported zip?} The PDF, the LaTeX, the images it uses, the .bib if any, a report of every check, and a README.
\item \textbf{How do you run it?} \cc{pip install -r requirements.txt}, install pandoc, Tectonic and Ghostscript, then \cc{python -m prarup.main}.
\item \textbf{Who did what?} Prateek: reading the paper and image checks. Krushna: building the PDF and checking it. Om: the window and the controller that joins everything.
\end{enumerate}
